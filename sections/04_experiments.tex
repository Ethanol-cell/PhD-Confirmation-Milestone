\section{Progress I: Representation-Transition Discovery}\label{sec:pca-progress}

\textbf{Progress I asks where a trained CNN changes from preserving visual
structure to organizing features around the classification task.} The evidence
is developed in a fixed order: construct comparable within-layer PCA-RGB maps;
inspect the complete CIFAR-10 depth progression; test class prototypes and
errors; compare trained and random networks; and then assess whether the
transition remains measurable on CIFAR-100 and ImageNet-1K.

\subsection{Dataset-wide, layer-specific PCA-RGB construction}

For layer $\ell$, image $x_i$, and spatial position $p$, let
\begin{equation}
    \bm f^{(\ell)}_{i,p}\in\mathbb{R}^{D_\ell}
\end{equation}
be the channel vector. A dataset-wide feature population
$\mathcal{F}_\ell=\{\bm f^{(\ell)}_{i,p}\}$ is sampled from the training split.
Its mean $\bm\mu_\ell$ and orthonormal principal component analysis (PCA)
basis $\bm V_\ell=[\bm v_{\ell,1},\bm v_{\ell,2},\ldots]$ are estimated with
streaming statistics so that the complete feature population need not be held
in memory \cite{pearson1901pca,hotelling1933pca}.

The first three signed coordinates are
\begin{equation}
    \bm z^{(\ell)}_{i,p}
    = (\bm f^{(\ell)}_{i,p}-\bm\mu_\ell)
      \bm V_{\ell,1:3}\in\mathbb{R}^{3},
    \qquad
    \bm C^{(\ell)}_{i,p}=\phi_\ell(\bm z^{(\ell)}_{i,p}),
    \label{eq:pca-rgb}
\end{equation}
where $\phi_\ell$ is a frozen layer-specific display transform mapping the
three coordinates to red, green, and blue (RGB). The basis, component signs,
and robust display limits are fitted on training data and then reused without
change for every validation or test image.

\textbf{The alignment is dataset-wide within each layer, not shared across
layers.} All images at layer $\ell$ use the same $\bm V_\ell$ and
$\phi_\ell$, so same-layer colour and coordinate comparisons are defined. Each
layer nevertheless has its own basis. A red region at layer $\ell$ should not
be interpreted as the same direction as a red region at layer $\ell+1$.
Cross-depth claims use explained variance, class separation, prototype
agreement, representational similarity, or other basis-invariant quantities
rather than raw colour identity.

\subsection{CIFAR-10 full-depth discovery}

CIFAR-10 is examined first because its ten classes make class-level structure
visually inspectable. A fixed set of images is propagated through every
registered spatial state of the selected trained CNN. The complete atlas is
used to identify three descriptive regimes: early feature extraction,
intermediate representation transition, and late class organization.

We provisionally summarize this progression as
\begin{equation}
    \text{feature extraction}
    \longrightarrow
    \text{spatial and semantic reorganization}
    \longrightarrow
    \text{class-oriented representation}.
    \label{eq:pca-progression}
\end{equation}
The terms describe observed behaviour rather than fixed architectural block
names. A candidate transition is supported only when rapid representational
change coincides with increasing semantic maturity while useful spatial
variation remains.

The main text will show six preregistered stages spanning the progression. The
all-layer atlas may be placed on a landscape appendix page if it becomes
unreadable at the report's normal text width; the main figure will link
directly to that appendix panel.

\subsection{CIFAR-10 class prototypes and wrong predictions}

The late-layer observation is tested at the class level. For each training
example, the signed PCA coordinate map is pooled into
\begin{equation}
    \bm r_i^{(\ell)}
    = \frac{1}{|\mathcal{P}_\ell|}
      \sum_{p\in\mathcal{P}_\ell}\bm z^{(\ell)}_{i,p},
    \qquad
    \bm c_k^{(\ell)}
    = \frac{1}{N_k}\sum_{i:y_i=k}\bm r_i^{(\ell)},
    \label{eq:pca-class-prototype}
\end{equation}
where $\bm c_k^{(\ell)}$ is the class prototype in the frozen layer basis.
For visualization, signed maps are averaged before clipping and RGB conversion;
averaging already clipped RGB pixels would introduce a nonlinear display bias.
A class mean map is shown beside a medoid example and a variability map so that
an apparently smooth mean is not mistaken for a typical individual image.

\textbf{The expected CIFAR-10 result is not merely that examples look similar,
but that within-class dispersion decreases and held-out prototype agreement
increases toward late layers.} We will test this expectation using within-class
dispersion, between-class separation, their ratio, nearest-prototype accuracy,
and bootstrap confidence intervals. Because every statistic is computed in one
frozen layer basis, the test does not rely on comparing colours across depth.

Misclassifications provide a stronger semantic test. For a held-out example
with true class $y_i$ and predicted class $\hat y_i$, define
\begin{equation}
    \Delta_i^{(\ell)}
    = d(\bm r_i^{(\ell)},\bm c_{y_i}^{(\ell)})
      -d(\bm r_i^{(\ell)},\bm c_{\hat y_i}^{(\ell)}).
    \label{eq:pca-error-margin}
\end{equation}
Positive $\Delta_i^{(\ell)}$ means that the representation is closer to the
predicted-class prototype than to the labelled-class prototype. The analysis
will evaluate every held-out error and will separately display strong
predicted-class alignment, ambiguous cases, and counterexamples according to a
frozen selection rule.

\subsection{Matched trained--random control}

A randomly initialized CNN can retain recognizable image structure at
unexpected depth because convolutions, residual paths, downsampling, and
nonlinearities impose architectural structure. \textbf{A visible spatial
pattern alone does not show that the network has learned class semantics.}

The control uses the identical architecture, tap registry, preprocessing, and
PCA-fitting protocol for trained and random models. Several trained seeds and
several independently initialized random seeds are compared. The visual panels
are paired by image and layer, while quantitative curves test class separation,
nearest-prototype accuracy, adjacent-layer change, and the error-alignment
margin. The expected discriminant is not whether a random map contains edges,
but whether trained representations develop reproducible class organization
beyond the random architectural baseline.

\subsection{CIFAR-100: hierarchy and increased class complexity}

CIFAR-100 tests whether the transition persists when one hundred fine classes
are nested within twenty coarse classes. Existing exploratory results show
weaker visually uniform late-layer colours than on CIFAR-10, but intermediate
spatial reorganization remains observable. The confirmatory analysis will use
the cached ConvNeXT-Base run where its metadata matches the frozen protocol and
will recompute any missing or incompatible statistics.

Fine- and coarse-label metrics are reported together. A layer may fail to form
a compact fine-class prototype while still separating coarse semantic groups;
this is more informative than concluding from an ambiguous three-coordinate
rendering that no class structure exists. Neural-collapse diagnostics,
high-dimensional class separation, and prototype agreement will complement
the PCA-RGB panels.

\subsection{ImageNet-1K: large-scale validation}

The previous pilot used ImageNet-100; the next large-scale test uses the full
ImageNet-1K validation setting. Visually identical late-layer class colours are
not assumed. ImageNet-1K has greater intra-class variation, background
variation, object scale variation, and class count, so the first three
principal coordinates may not display the complete semantic geometry.

The primary question is instead whether a measurable transition remains:
semantic separation should increase, spatial organization should change, and
the location of the strongest change should be reproducible across selected
CNN families. Main-text panels will use a fixed, semantically stratified class
and image manifest. Quantitative statistics will use the full available
validation cohort, subject to declared compute limits; the appendix will hold
the larger atlas and layer registry.

\subsection{Current interpretation and claim boundary}

The completed observations support further investigation of RQ1, but they do
not yet establish it.
\textbf{The important shift is from treating a final heatmap as the entire
explanation to studying how spatial geometry is formed across depth.} The next
evidence must establish that the transition is measurable, that its location
is not selected retrospectively from a desirable visualization, and that its
geometry supports localization or knowledge transfer.

The PCA-RGB maps remain a discovery and communication device. Same-layer
prototype agreement, trained--random differences, and basis-invariant depth
metrics supply the confirmatory evidence. The \methodname{} and \jmethod{}
studies then test two practical uses of transition-related geometry.
\methodname{} uses it for explanation, whereas \jmethod{} uses it for knowledge
transfer.
