\section{Full PCA-RGB Evidence Atlases}
\label{sec:pca-rgb-appendix}

The main report uses compact figures so that each visual result remains beside
its explanation. This appendix preserves the wider evidence sets at readable
scale. It does not add new samples or change the quantitative results. No
subplot letters are used; class names, model conditions, layer identifiers, and
metric labels provide the required references directly.
