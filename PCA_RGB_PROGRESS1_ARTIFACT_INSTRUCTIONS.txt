PURPOSE

Create every paper-ready artifact needed to support Progress I of the PhD
confirmation report. The scientific question is where a trained convolutional
neural network (CNN) changes from preserving generic visual structure to
organizing spatial features around the classification task. The artifact set
must support or reject this proposed sequence:

    feature extraction -> spatial/semantic transition -> class organization

Do not treat an attractive principal component analysis red-green-blue
(PCA-RGB) map as proof. The required evidence consists of a frozen qualitative
atlas, held-out class/prototype tests, trained-versus-random controls, and
basis-invariant depth metrics.

The required dataset order is:

1. CIFAR-10: full-depth discovery, same-class prototypes, wrong predictions,
   and trained-versus-random comparison.
2. CIFAR-100: test fine-class and coarse-class structure under higher class
   complexity.
3. ImageNet-1K: large-scale validation of the transition; do not assume that
   late-layer class colours will be visually uniform.

The earlier ImageNet-100 pilot may be reported as prior exploratory evidence,
but it is not a substitute for the requested ImageNet-1K run.

NON-NEGOTIABLE CLAIM BOUNDARIES

- Fit a separate dataset-wide basis for every layer. All examples at layer l
  share that layer's basis, but layer l and layer l+1 do not share a basis.
- Never infer cross-layer semantic identity from RGB colour identity. Cross-
  layer conclusions must use basis-invariant metrics or an explicitly fitted
  alignment.
- Fit PCA, signs, and display limits on training/calibration data only. Freeze
  them before viewing held-out results.
- Average signed PCA coordinate maps before clipping and RGB conversion. Never
  average already clipped RGB images.
- A random network may preserve edges or shapes. Visible structure is not
  evidence of learned semantics. The trained-random claim must rest on class
  organization and reproducibility metrics.
- The wrong-prediction observation is currently semantic. Do not call it
  causal or faithful attribution. Report the full held-out error distribution,
  not only selected examples.
- Do not claim that dataset complexity causes weaker late-layer colours unless
  architecture, preprocessing, and model-quality confounds have been addressed.
- Do not cherry-pick layers, images, classes, seeds, or failures. Create and
  save selection manifests before rendering final panels.

STREAMING PCA IMPLEMENTATION

Run feature extraction on the GPU in model.eval() with torch.inference_mode().
Use automatic mixed precision for the forward pass only when it does not change
predictions; cast sampled feature vectors to float64 before accumulation. Never
materialize the full dataset x spatial positions x channels matrix.

For a layer with batch feature tensor F of shape [B,C,H,W], move channels last
and flatten sampled positions to X of shape [m,C]. Use a deterministic,
spatially stratified sampler. Cap the total sampled vectors per layer at:

- CIFAR-10: 250,000 vectors, balanced across classes and images.
- CIFAR-100: 500,000 vectors, balanced across fine classes.
- ImageNet-1K: 1,000,000 vectors, balanced across classes as far as the
  available training/calibration split permits.

Use all spatial positions when H*W is smaller than the requested per-image
sample count. Otherwise sample one point from each cell of a deterministic
approximately uniform grid, with the run seed controlling within-cell offsets.
Record the realized count for every layer.

Maintain count n, mean mu, and centred second-moment matrix M2 with blockwise
parallel/Welford updates. For existing state (n, mu, M2) and a block X with m
rows, block mean mu_b, and M2_b=(X-mu_b)^T(X-mu_b):

    delta = mu_b - mu
    mu_new = mu + delta * m/(n+m)
    M2_new = M2 + M2_b + outer(delta,delta) * n*m/(n+m)
    n_new = n + m
    Sigma = M2/(n-1)

Use torch.linalg.eigh(Sigma), sort eigenvalues descending, and retain at least
the first 32 components. Accumulate on the GPU in float64 when memory permits.
If a covariance matrix does not fit, keep feature extraction on GPU and move
only block sufficient statistics to a CPU float64 accumulator. Process tap
groups under an explicit memory budget; do not fall back to storing all raw
features. Log GPU peak memory and samples/second.

Fix each eigenvector sign deterministically: locate its largest absolute
loading and require that loading to be positive. Record the selected loading
index and sign. When adjacent eigenvalues are nearly tied (relative gap below
1e-4), mark individual components unstable and base scientific comparisons on
their joint subspace rather than their arbitrary ordering.

Validate the streaming implementation on a small tensor by comparing its mean,
covariance, eigenvalues, and subspace with an exact in-memory calculation.
Required tolerances are 1e-8 for mean/covariance in float64 and principal-angle
error below 1e-5 radians for well-separated components.

FROZEN PCA-RGB DISPLAY TRANSFORM

Project signed scores z=(f-mu)V_1:3. For each layer and component, estimate the
1st and 99th percentiles from the same training/calibration feature stream used
for PCA. Freeze these six values. Map each coordinate independently to [0,1]:

    rgb_j = clip((z_j - q01_j)/(q99_j - q01_j), 0, 1)

If q99_j-q01_j < 1e-12, mark the component degenerate and stop the figure
generation for that layer. Do not normalize per image or per class. Render a
native-resolution map and a bilinearly upsampled display map; quantitative
spatial computations use native maps unless a metric explicitly requires a
common grid. Save the unclipped float32 coordinate map when storage permits.

CLASS PROTOTYPES AND METRICS

Let z_i,p^(l) be the frozen d-dimensional PCA coordinate at spatial position p,
using d=32 for quantitative tests and d=3 only for RGB display. Define the
pooled descriptor and training class prototype:

    r_i^(l) = (1/P_l) sum_p z_i,p^(l)
    c_k^(l) = (1/N_k) sum_{i:y_i=k} r_i^(l)

Standardize each retained coordinate with training-set scale before Euclidean
distance so PC1 cannot dominate only because it has higher variance. Report an
unstandardized sensitivity result separately.

For each layer compute:

1. Explained variance ratio EVR_j=lambda_j/sum_q lambda_q for j=1,2,3,32 and
   cumulative EVR_3 and EVR_32.
2. Within-class dispersion
      S_W = (1/N) sum_i ||r_i-c_yi||_2^2.
3. Between-class dispersion
      S_B = (1/K) sum_k ||c_k-c_bar||_2^2.
4. Fisher-style separation F=S_B/(S_W+1e-12).
5. Nearest-class-prototype accuracy on held-out examples.
6. Neural-collapse NC1, trace(Sigma_W)/trace(Sigma_B), plus an NC2
   class-mean equiangularity residual when K-1 does not exceed the tested
   subspace dimension. Clearly state when NC2 is not identifiable.
7. Same-class map similarity: centred cosine similarity between each signed
   three-coordinate map and its training class mean map after adaptive average
   pooling to a common 8x8 grid. Report within-class and between-class
   distributions; do not use RGB pixel similarity.

For class visualization, compute the signed mean map, per-pixel standard
deviation map, and medoid example for every CIFAR-10 class. Use exactly 500
training images per CIFAR-10 class for the prototype. For CIFAR-100 use all
available training images per class, reporting both 100 fine prototypes and 20
coarse prototypes. For ImageNet-1K use the available training/calibration
examples per class and record unequal counts.

WRONG-PREDICTION ANALYSIS

For every held-out error define:

    Delta_i^(l) = d(r_i,c_yi) - d(r_i,c_yhat_i)

Positive Delta means closer to the predicted-class prototype. Report:

- proportion with Delta>0 and a 95% stratified bootstrap confidence interval;
- median Delta and bootstrap interval;
- true-prototype and predicted-prototype nearest-neighbour ranks;
- results by confidence quartile and confusion pair;
- comparison with correct predictions and a label-permutation baseline.

The qualitative figure must contain six CIFAR-10 errors chosen by a frozen
stratified rule: two from the upper quartile of positive Delta, two nearest
zero, and two negative-Delta counterexamples. Break ties by dataset index.
Never choose examples for visual attractiveness.

TRAINED-RANDOM AND TRANSITION METRICS

For trained and random models compute all class metrics above. Additionally:

- Linear centred kernel alignment (CKA) between adjacent layers from a fixed
  held-out image cohort, using spatially pooled and standardized features:

      CKA(X,Y) = ||X^T Y||_F^2 /
                 (||X^T X||_F ||Y^T Y||_F).

- Spatial affinity-change score. Adaptively pool each layer to 8x8, normalize
  each spatial feature vector, form G_l=U_l U_l^T, and compute

      AChange_l = 1 - cos(vec(center(G_l)), vec(center(G_l+1))).

- Semantic gain between consecutive taps: change in log(Fisher separation)
  and change in nearest-prototype accuracy.

Do not collapse these measures into one score for the primary analysis. Define
a candidate transition interval before inspecting final maps as taps where
AChange is in the top 20% of that model's adjacent-layer values, semantic gain
is positive, and the feature map remains at least 4x4. Report all qualifying
taps and sensitivity to top-10%, top-20%, and top-30% thresholds.

Use 2,000 image-level stratified bootstrap replicates for 95% confidence
intervals. For trained-random differences, pair on dataset examples and layer
semantic slots. Across multiple layer tests, report Holm-adjusted p-values as a
secondary aid; emphasize effect sizes and intervals. Aggregate seeds with mean
and standard deviation and show individual seed traces faintly.

STOP CONDITIONS

Stop and report rather than improvising when: a checkpoint cannot be traced;
dataset class mappings differ; test data appears in a PCA fit; preprocessing
cannot reproduce model accuracy; a cache lacks required metadata; a requested
Hugging Face model is gated and HF_TOKEN is absent; GPU memory remains
insufficient after tap grouping and CPU-statistic fallback; or the measured
results contradict the prose. Contradictory results require revising the
report claim, not altering the analysis or selection rule.
